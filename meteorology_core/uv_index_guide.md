# UV Index Guide — India
Source: WHO, WMO, ICMR UV Exposure Guidelines

## UV Index Scale
| UV Index | Exposure Category | Colour | Sun Protection Needed |
|---------|-----------------|--------|----------------------|
| 1–2 | Low | Green | Minimal protection |
| 3–5 | Moderate | Yellow | Cover-up; sunscreen SPF 15+ |
| 6–7 | High | Orange | SPF 30+ sunscreen; hat; shade 12–4 PM |
| 8–10 | Very High | Red | SPF 50+ sunscreen; limit outdoor time |
| 11+ | Extreme | Violet/Purple | AVOID midday sun; SPF 50+ mandatory |

## India UV Index Patterns
| Region | Peak UV Month | Max UV Index | Notes |
|--------|--------------|-------------|-------|
| High Himalayas | May–Jun | 14–16 | Altitude amplifies UV (10% increase per 1000m) |
| Rajasthan | April–June | 12–13 | Minimal cloud cover; high solar angle |
| Tamil Nadu | March–May | 11–12 | Near-equatorial; year-round high UV |
| Delhi NCR | May | 10–11 | Smog reduces UV but ozone depletion risk |
| Northeast | June | 9–10 | Partly offset by monsoon cloud cover |

## UV and Ozone Depletion Context India
- India lies between 8°N–37°N latitude → High solar angle → High UV
- Ozone column over India: ~275–305 Dobson Units (relatively low = more UV)
- Significant UV spike: March–May before monsoon cloud cover builds

## Agricultural UV Impact
- Positive: UV helps in suppression of some fungal spores on crop surfaces
- Negative: Excessive UV (> 10) can damage leaf chlorophyll; reduce photosynthesis
- Greenhouse crops: UV filtering screens recommended when UV > 9

## Outdoor Worker Protection (Construction, Farm Labour)
| UV Level | Action |
|---------|--------|
| 6–7 (High) | Full-sleeve cotton shirt mandatory; work in shade 12–2 PM |
| 8–10 (Very High) | SPF 50 sunscreen on exposed skin; 45 min break per 2 hours |
| 11+ (Extreme) | No outdoor work 11 AM – 4 PM; strict shade requirement |
